# Insights & Vision

A public reading room for Ergon analysis, research notes, explainers,
counterarguments, and long-form vision. The aim is not to manufacture
certainty; it is to make reasoning inspectable and useful.

## Collections

| Collection | Purpose | Publication state |
| --- | --- | --- |
| Analysis | Source-grounded examination of technical or network questions | Planned |
| Vision notes | Clearly labeled arguments about possible directions | Planned |
| Research notes | Questions, methods, intermediate results, and counter-evidence | Active |
| Reproductions | Portable public packs and independent results | Not yet published |
| Network briefings | Factual changes and sourced ecosystem context | Planned |

## Active research horizon

- protocol-native assets;
- proportional rewards;
- cyphercash;
- supply and emission;
- descriptive price context without forecasting;
- hashrate responsiveness and elasticity;
- difficulty adjustment;
- block size and propagation;
- security and fee markets.

The canonical status and evidence fields for these topics live in
[`cockpit/cockpit.yaml`](../cockpit/cockpit.yaml).

## Publication standard

Research entries disclose, as applicable:

- the question and claim boundary;
- sources and licensing;
- methods, models, and software;
- public data and transformations;
- units and definitions;
- assumptions and uncertainty;
- limitations and counter-evidence;
- a portable reproduction pack.

`Observed` is not `Reproduced`. A simulation is not a network observation. A
vision note is not an accepted implementation or consensus rule.

## First flagship thread: protocol-native assets

The current public status is `research` / `Open Question`. The work begins with
reviewed public prior art, an independently authored specification, explicit
compatibility and threat models, test vectors, activation analysis, and
portable implementation evidence. Inspiration does not become implementation
authority.
