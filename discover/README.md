# Discover Ergon

Ergon Lab is building a public path from first principles to technical detail.
This space will explain what Ergon is trying to make possible, how its ideas fit
together, and which questions remain unsettled.

## Start here

| Path | What it will answer | Status |
| --- | --- | --- |
| Why Ergon? | The motivation, trade-offs, and intended public value | Planned |
| How the network works | Transactions, blocks, mining, validation, and finality concepts | Planned |
| Supply and emission | The rules, units, derivation, and auditable historical path | Research |
| Native assets | The opportunity, requirements, threat model, and open design space | Research |
| Glossary | A shared vocabulary with source-grounded definitions | Planned |

## Reading law

Every page should be useful at two levels:

1. a plain-language explanation that does not assume protocol expertise;
2. a path to primary sources, explicit assumptions, and reproducible evidence.

An explainer may simplify presentation, but it must not silently simplify away
uncertainty or turn an open research question into a protocol fact.

## Evidence labels

| Label | Meaning |
| --- | --- |
| `Explainer` | A source-grounded explanation of established material |
| `Hypothesis` | A falsifiable proposition that has not been established |
| `Simulation` | A result produced by a declared model and inputs |
| `Observed` | A bounded observation from a declared environment |
| `Reproduced` | An independently repeated result using reviewed public inputs |
| `Open Question` | A named question whose answer is not yet supported |
